## About This Book

This book teaches JavaScript developers how to build real-world AI-powered applications using Node.js. Every concept is explained from scratch with real-life analogies, diagrams, and hands-on code.

**What you will learn:**
- AI fundamentals for JavaScript developers
- Working with LLMs (Gemini, OpenAI, Claude)
- Prompt engineering and structured outputs
- Embeddings and vector databases (Pinecone)
- RAG (Retrieval-Augmented Generation) pipelines
- AI Agents with LangChain.js
- Model Context Protocol (MCP)
- Three complete real-world projects

**Tech Stack:** Node.js, Express.js, Google Gemini, LangChain.js, Pinecone, MCP

## How to Use This Repository

Each chapter has its own folder containing:
- `code/` — All executable code examples
- `images/` — Diagrams and figures used in the chapter
- `resources.md` — Helpful links and references

To run any code example:
```bash
cd chapter-01/code
npm install
node 01_async_demo.js
```
